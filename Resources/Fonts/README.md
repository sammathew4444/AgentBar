JetBrainsMono Nerd Font (Regular and Bold, ligatures variant) from Nerd Fonts v3.5.1,
`patched-fonts/JetBrainsMono/Ligatures/` in <https://github.com/ryanoasis/nerd-fonts>.
Licensed under the SIL Open Font License 1.1; see `OFL.txt`.

This is the family Omarchy's bar resolves `monospace` to by default. `Scripts/bundle.sh` copies these
files into `AgentBar.app/Contents/Resources/Fonts/`, and `ATSApplicationFontsPath` in `Info.plist`
registers them at launch.
