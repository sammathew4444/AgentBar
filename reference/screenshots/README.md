# Screenshots

## panel-codex.webp

The agents panel open on a real Omarchy Quattro install, default Tokyo Night theme, provided by
the project owner. 630 × 846 px, cropped to the top-right corner of the screen, so the bar's
right end and the panel's top-right position are visible.

- Shows: the bar glyph, underlined while its panel is open; the panel with Codex selected in a
  two-agent switch (Claude Code, Codex); one Weekly limit (7%, "Resets in 4d 17h"); seven days
  of tokens ending in a bold "Today"; one model row ("GPT 5.6 Sol", 165.5M).
- Scale: not recorded at capture. Measured: the card is 605 px wide for a 380-unit card, so
  about 1.59 px per unit (display scale and `[font] base-size` combined).
